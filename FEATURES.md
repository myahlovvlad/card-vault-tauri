# Product scope

## MVP

- OCR from business-card photos with user confirmation.
- Contact catalog with folders.
- Multiple photos per contact.
- Star / highlighted cards and priority sort.
- Search.
- Local persistence.
- JSON backup/import, CSV export, vCard export.
- Responsive browser UI + Tauri shell.
- "My Cards": author your own card(s), present as a full-screen flip QR (vCard), share via Web Share API / .vcf.
- QR scanner: decode another card's QR (or generic vCard) straight into the confirm-and-save flow.

## Next integrations

- CRM adapters: Bitrix24 / amoCRM / HubSpot / custom REST.
- Contacts: Google / Microsoft / device address book.
- Calendar: create follow-up event from a card.
- Desktop-to-mobile encrypted sync.
- Reviewer role: comments and star only.
